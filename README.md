# Powerum (for Fabric)

An open-source lightweight **Minecraft** optimization mod made to prevent **CPU thermal throttling** and **memory crashes**.

---

# FAQ

### How do I install this mod?
Read the [Installation](#installation) guide below.

### Powerum is not working or crashing!
If something goes wrong, check our [Issues](#issues) section for guidance on how to report a bug properly.

### Is this mod client-side or server-side?
Powerum is strictly client-side. It does not need to be installed on the server, only in your game client.

### How can I access the source code?
Powerum is fully open-source. You can explore, fork, or build the source code directly from this GitHub repository.
For more details read the [sources](#sources) guide below.

# Installation

<p style="text-align: left;">
   <a href="https://fabricmc.net/"><img src="https://cdn.jsdelivr.net/npm/@intergrav/devins-badges@3/assets/cozy/supported/fabric_vector.svg" alt="Fabric" style="margin: 5px 5px;"> </a>
</p>

- Download the [Fabric modloader](https://fabricmc.net/).
- Download and move the Powerum `.jar` file into your `.minecraft/mods` folder.
