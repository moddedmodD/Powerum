# FAQ

### How do I install this mod?
Read the [Installation](https://github.com/moddedmodD/Powerum/blob/master/docs/DESCRIPTION.md) guide below.

### Powerum is not working or crashing!
If something goes wrong, check our [Issues](https://github.com/moddedmodD/Powerum/blob/master/docs/DESCRIPTION.md) section for guidance on how to report a bug properly.

### Is this mod client-side or server-side?
Powerum is strictly client-side. It does not need to be installed on the server, only in your game client.

### How can I access the source code?
Powerum is fully open-source. You can explore, fork, or build the source code directly from this GitHub repository.
For more details read the [sources](https://github.com/moddedmodD/Powerum/blob/master/docs/DESCRIPTION.md) guide below.
